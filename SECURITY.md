# Sécurité

La petite jauge est conçue pour un usage local ou sur un réseau privé de confiance. L'API n'a pas d'authentification; ne l'expose pas directement à Internet.

## Signaler une vulnérabilité

N'ouvre pas d'issue publique pour signaler une vulnérabilité. Utilise le signalement privé de vulnérabilité GitHub lorsqu'il est activé pour le dépôt. Si ce canal n'est pas disponible, contacte le mainteneur par le moyen privé indiqué sur son profil GitHub.

Ne joins jamais la base `carnet_essence.db`, des fichiers `.env`, ni des trajets ou pleins réels à un signalement.
